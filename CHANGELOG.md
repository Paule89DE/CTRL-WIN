# Changelog

## 0.1.0-alpha.1 - 2026-10-12

First published alpha of CTRL-WIN.

- Organize 262 Windows shortcuts into 12 numbered categories with concise English Windows names.
- Include system folders, Control Panel dialogs, administrative tools, System Properties, diagnostics, and direct Windows Settings pages.
- Add Windows Accessories, including Remote Desktop Connection, Calculator, Notepad, Paint, and Snipping Tool.
- Use native Windows resources for shortcut and folder icons, with checks at 16, 32, 48, 96, and 256 pixels.
- Apply Videos templates and Extra large icons to the collection and documentation folders, including matching open Explorer windows.
- Refresh stale folder imagery through folder timestamps and Shell notifications.
- Provide targeted download-marker removal and a three-step setup launcher.
- Keep 12 REG files and 5 CMD files as explicit optional tweaks, with documented scope and reversal behavior.
- Skip Git metadata during setup traversal.
- Include an actual Explorer screenshot, a full purpose/target catalog, and detailed English usage, tweak, and maintenance guides.

The original 250 shortcut launch parameters and REG operations are preserved. The 12 accessories add portable Windows app launch targets. Optional tools and Settings pages can vary by Windows version, edition, hardware, and installed components. This alpha does not claim exhaustive execution testing of every target on every Windows release.
